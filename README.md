# taskManager_cpp
Консольный менеджер задач на С++

- добавляет, удаляет и отмечает задачи
- автоматически сохраняет и загружает состояние из 'tasks.txt'
- обрабатывает некорректный ввод

--- Как запустить ---
g++ main.cpp Task.cpp TaskManager.cpp 

* Task.h - описывает интерфейс, что класс делает
* Task.cpp - описывает интерфейс, как класс делает
* TaskManager.h - управляет коллекцией задач
* TaskManager.cpp - Реализация логики менеджера задач
